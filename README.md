# E-commerce
E-commerce — электронная торговля, или электронная коммерция. Данный проект - это ядро для интернет-магазина. 
С помощью этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

## Содержание
- [Категории товаров]
- [Товары]. У всех товаров и их подкатегорий имеется общая функциональность. 
Для удобства при создании нового товара в консоль выводится информация о том, 
от какого класса и с какими параметрами был создан объект
- Подкатегории товаров:
    - Смартфоны
    - газонная трава
